## Direct Comparison

|Feature|	NASM|	Yasm|
|-|-|-|
|Origin & Nature|Original x86 assembler|Ground-up rewrite / modular clone of NASM|
|Syntax Support|Intel syntax|Intel (NASM), GAS (AT&T), and more natively|
|License|BSD-2-Clause|BSD-3-Clause / "New" BSD|
|Architecture / Design|Monolithic / classic codebase|Modular library design (libyasm) for easy integration|
|Maintenance Status|Actively and widely maintained (used by Chromium, FFmpeg, etc.)|Largely unmaintained / inactive compared to NASM|
